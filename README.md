# Savona Startup

Sito di Savona Startup APS, ricostruito in Next.js e pronto per Vercel.

Stesse sezioni del sito attuale: home, diventa socio, partnership, chi siamo, vision e mission, organigramma. Dona ed Eventi restano collegamenti esterni (SumUp ed Eventbrite).

## Brand

- Titoli: Montserrat Bold
- Testo: Montserrat Regular
- Colori: `#0061A8`, `#F5A826`, `#E2F3FA`

## Sviluppo

```bash
npm install
npm run dev
```

## Deploy su Vercel

Importa il repository. Il framework rilevato è Next.js: non servono variabili d'ambiente. Il comando di build è `next build`.

Pagine:

- `/`
- `/vantaggi-socio`
- `/sei-unazienda-diventa-partner`
- `/associazione`
- `/vision`
- `/organigramma`
